# Week 1: Basics, Variables and Strings

Rule for every day: watch the 3 videos, close them, write the code **from memory**, then change it. Do the exercises below after that.

## Day 1: Comments and print
- [ ] Print an ID card about yourself on 5 lines. Put a comment above each line.
- [ ] Draw a triangle or a square with `*`.
- [ ] Change it: put a border around the card.

## Day 2: Variables
- [ ] Save your name, age and city. Print them in one sentence.
- [ ] Swap the values of two variables without a third variable.
- [ ] Calculate your age in days.

## Day 3: Escape characters
- [ ] Print a Windows file path that has backslashes.
- [ ] Print a sentence that has both `"` and `'`.
- [ ] Print a small table using `\t` and `\n`.

## Day 4: Indexing and slicing
- [ ] Take your full name and print the first letter, the last letter and the first 3 letters.
- [ ] Reverse a word using slicing.
- [ ] Print only the even-position letters of a long word.

## Day 5: String methods
- [ ] Clean a text that has extra spaces and mixed letters (`strip`, `title`, `lower`).
- [ ] Build an email address from a first name and a last name.
- [ ] Use `replace` and `count` on a paragraph you choose.

## Day 6: Formatting and numbers
- [ ] Print an invoice with f-strings: 3 items and a total.
- [ ] Convert a temperature from C to F.
- [ ] Calculate the area and the perimeter of a circle.

## 🏁 Weekly project: Student ID Card
Build a program that prints a nicely formatted ID card: name, major and year. It must also calculate the graduation year and print it.

Requirements:
- Use variables and f-strings.
- Add a short README that shows a screenshot of the output.
- If `input()` is not in the course yet, use variables first, then change it when you learn `input()`.
