# Week 2: Numbers, Input and Lists

The lesson ranges in the course may be a little different from my topics. Move an exercise to a different day if the video comes on another day.

Rule for every day: watch the 3 videos, close them, write the code **from memory**, then change it.

## Day 1: Numbers and operators
- [ ] Calculate the area and the perimeter of a rectangle.
- [ ] Convert 475 minutes to hours and minutes using `//` and `%`.
- [ ] Print the last digit of any number using `%`.

## Day 2: Type conversion
- [ ] Convert the string `"42"` to an integer and add 8 to it.
- [ ] Calculate the average of 3 grades and round it to 2 places.
- [ ] Print the `type()` of 5 different values.

## Day 3: `input()` and f-strings
- [ ] Ask for a name and an age. Print how many years are left until the age of 100.
- [ ] Calculate simple interest from the amount, the rate and the years (all from `input()`).
- [ ] Ask for a noun, a verb and an adjective, then print a funny sentence.

## Day 4: Lists, part 1
- [ ] Make a shopping list. Add, insert and remove items.
- [ ] Print the list in reverse order using slicing.
- [ ] Find the biggest number in a list without using `max()`.

## Day 5: Lists, part 2
- [ ] Calculate the sum of a list without using `sum()`.
- [ ] For a list of grades, print the min, the max and the average.
- [ ] Swap the first and the last items in a list.

## Day 6: Project day
Build **both** small projects below.

### Project A: Bill and Tip Splitter
Ask for the bill amount, the tip percentage and the number of people. Print the tip, the total and the amount for each person.

### Project B: Unit Converter
Convert these units from user input: km and miles, kg and pounds, Celsius and Fahrenheit.

Requirements for both:
- Use `input()` and f-strings with 2 decimal places.
- Each project gets its own folder under `projects/` with a README: what it does, how to run it, and an example.
- Conditions are not in the course yet, so skip input validation now. Add it after the conditions lessons.
