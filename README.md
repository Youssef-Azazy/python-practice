# Python Practice 🐍

My daily Python practice, from zero to professional. I follow the **Elzero Web School** "Mastering Python" playlist (3 videos per day), then write the code again from memory and change it.

## 📁 Structure

```
python-practice/
├── week-01/        daily exercises + the weekly project
├── week-02/
├── ...
└── projects/       the bigger portfolio projects, one folder each
```

Each `week-XX` folder has a `README.md` with the daily plan. My solutions go in the same folder as `Day_01.py`, `Day_02.py` and so on. HackerRank solutions go in `hackerrank_*.py` files.

## 🔁 My daily routine (3 hours)

| Time | What I do |
|---|---|
| 30 min | Watch 3 videos |
| 90 min | Close the video, write the code from memory, then change it |
| 30 min | Course assignments |
| 30 min | Review, then commit to this repo |
